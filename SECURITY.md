# Security Policy

## Supported version

Security fixes are applied to the latest published release. Version `0.5.2` is an early public release and has not yet established a long-term support window.

## Reporting a vulnerability

Do not open a public issue containing exploit details, credentials, private data, or unredacted diagnostic output. Use the repository's private security-advisory channel. If that channel is unavailable, retain the report locally rather than exposing sensitive material.

Include the affected version and build, operating system and Python version, a minimal synthetic reproduction, the security impact, and whether the default loopback-only configuration is affected.

The detailed runtime trust boundaries are documented in [`docs/SECURITY.md`](docs/SECURITY.md).
